# and-design-system-audit 程序项目设计文档体系合理性校验

本 skill 校验程序项目设计文档体系本身的合理性：判定标准**全部在审计执行时从规范文本抽取**，skill 不写死任何文档类型或路径。规范冲突/空缺即中断、只报事实，不替规范拍板。作为 change 审计（and-openspec-upstream-audit）的上游侧补充，回答「设计文档体系本身好不好」而非「change 是否满足上游」。

**本 skill 目录**：即本 `SKILL.md` 所在目录。`references/` 在此目录下。

## 适用范围（权威源：references/audit-criteria.md）

- 面向**程序项目**设计文档体系，由用户**手动触发**，输入为项目根目录或指定文档
- 判定为 **AI 语义判断**，判定标准从规范文本**运行时抽取**，skill **不发明规范、不裁决规范冲突**
- **只读不自动修**：审计只报告问题，不自动修改文档或规范
- **边界**：不审计 openspec change（用 and-openspec-upstream-audit）、不校验技术文章（用 and-validate-article）、不回填上游引用

## 工作流

### Step 0：规范引导发现

1. **读项目根目录 `AGENTS.md`**，定位其指向的规范体系（用户级 `AGENTS.md` 路径）；无指针时沿可用的用户级配置查找规范体系
2. **判定项目类型**（配置/文档/程序），确定适用规范集（文档规范、迭代规范等，以规范引导为准）
3. 配置/文档项目无设计文档层 → 按「该层不存在」**声明缺位**处理，不误报存在性缺失

### Step 1：自动抽取文档模型（门禁）

**规范自洽是审计的前提，抽取即门禁**。

1. **读适用规范文本**，AI 识别文档产物类型（doc_types）及每类的：
   - `location`（落点）
   - `structure`（结构要求）
   - `content`（内容要求）
2. 每条抽取结果**必引「规范依据（文件+条款）」**，供人工覆核
3. **自检**，命中任一即中断：
   - **冲突**：同一文档类型的落点在两个及以上规范中说法不一
   - **空缺**：某文档类型在规范中无明确落点定义
   - 命中 → 输出「规范问题清单」（类型/涉及文档类型/规范位置/事实），**不审计文档、不提规范修复方案**
   - 模型完备 → 进入三关

### Step 2：位置关

对照抽取模型的 `location`，按落点**模态**逐一检查各文档类型：

- **无条件必须**（规范标 [必须]）：落点缺失 → 不合规
- **有条件必须**（规范标「有X则必须」）：先基于项目现状（代码/文档/配置）判定条件——条件满足则缺失不合规、不满足则通过

### Step 3：结构关

对照抽取模型的 `structure`，检查各文档结构是否满足规范要求。

### Step 4：内容关

对照抽取模型的 `content`，检查各文档内容是否满足要求（逐层细化、覆盖上层、语言、格式等均以抽取内容为准）。

### Step 5：报告

按两种口径输出**只读报告**（不自动修改任何文件）：

**文档审计报告**（模型完备、三关完成时）——每条 finding：

```
关 / 文档 / 判断(通过/不合规) / 规范依据(文件+条款) / 现状 / 基于规范的修改方向
```

修改方向**必须保留规范自身的语气**：规范标 [必须] 写「按 §x 必须…」，标 [推荐] 才可写「按 §x 建议…」；规范未规定改法时引规范原文，不发明。报告**不引入严重度/优先级分级，不发明规范外的豁免**。

**规范中断报告**（门禁命中冲突/空缺时）——仅规范问题清单：

```
类型(冲突/空缺) / 涉及文档类型 / 规范位置(文件+条款) / 事实
```

任一命中门禁，报告「规范问题清单」段后即终止，不进入三关。

## 修复模式

审计**永远只报告**：文档不合规输出「规范依据/现状/基于规范的修改方向」（保留规范 [必须]/[推荐] 语气），规范不合规只列冲突事实与涉及位置，**绝不自动改**文档或规范；怎么修由人决策（规范怎么修属未来事项）。skill **严格执行抽取的规范，不软化、不发明豁免、不引入严重度分级**。

## 输出语言

报告面向用户，使用简体中文；技术术语（openspec/roadmap/markdown 等）与代码标识符保留英文。具体边界：面向人阅读的内容（报告正文、关名、问题描述）用简体中文；机器字段（路径、CLI flags、JSON 字段名）保留英文。
