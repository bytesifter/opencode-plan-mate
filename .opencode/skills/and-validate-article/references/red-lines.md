# 发布红线 → hard-fail 映射机制

本文件只定义**映射机制**，**不列举红线清单**——红线清单属源内容，运行时从适用源抽取（规范驱动）。

## 映射机制

- **判定标准来源**：适用源中的「发布红线」条款（本地规范默认取 `AGENTS-article.md §3.7`；外部源取源文本），运行时抽取，每条附带规范依据（文件 + 节）
- 任一红线命中 → **hard-fail**：按源语义判定为不可发布 / 一票否决，并在该源报告的「红线」段列出
- 命中项须引「规范依据（文件 + 节）」与文章定位（行 / 章节）

## 分工

- **可机械判定的红线**（如命中词表类的规则）：由规则集中对应的 `machine` 规则检出（`engine.py`）
- **需语义判断的红线**：由 L2 AI 判定，命中标 hard-fail
- **适用性判定**：抽取时判断源红线是否适用于文章评审；源文本定义的是非文章语义的红线（如标注员行为红线：刷量 / 抄袭 / 洗稿）→ 判定不适用，跳过并记 `coverage_gaps`

## 超出能力范围（不查）

- 内容审核类（违法违规 / 政治敏感 / 色情低俗）与平台风控类行为，超出本 skill 能力，不检查
